# Uso de IA

Usamos Claude como ayuda para el TP. Acá anotamos para qué y qué le pedimos.
Todo lo que entregamos lo revisamos y lo podemos explicar nosotros.

## Para qué la usamos

- Entender las consignas del TP y el cronograma.
- Elegir el cliente (nos ayudó a comparar las opciones).
- Armar las preguntas para la entrevista con el cliente.
- Dudas sobre cómo crear y configurar el repositorio.

## Ejemplos de lo que le pedimos

- "De los clientes que hay, ¿cuál es el mejor para elegir?"
  Nos recomendó el taller mecánico y nos explicó por qué. Elegimos el taller.
- "Armame las preguntas de la entrevista."
  Nos dio una lista de preguntas por tema y las usamos como base.
